# IndieHub

Простой клиент в стиле **Steam** + магазин в стиле **itch.io**.

- **Десктоп-клиент** — нативный C++ (webview)
- **Веб-интерфейс** — чистый HTML + CSS + JS
- **Бэкенд** — PHP + MySQL (XAMPP + phpMyAdmin)
- Таблицы создаются **автоматически** при первом запуске

---

## Структура проекта

```
itch-steam-like/
├── client/                 # C++ десктоп-клиент (как Steam)
│   ├── main.cpp
│   └── README.md
├── web/                    # Веб-часть (кладётся в htdocs)
│   ├── index.php           # Все страницы: каталог, игра, библиотека, загрузки, профиль
│   ├── config.php          # Настройки БД
│   ├── db.php              # Подключение + авто-миграция + демо-данные
│   ├── auth.php            # Авторизация, сессии, CSRF
│   ├── media.php           # Процедурные SVG-обложки и скриншоты
│   ├── api/
│   │   ├── auth.php        # API входа/регистрации
│   │   ├── games.php       # API каталога, покупок, комментариев, скачиваний
│   │   └── user.php        # API профиля: стата, активность, баланс
│   ├── files/              # Сюда складываются сгенерированные сборки
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── app.js
├── database/
│   └── schema.sql          # Схема (на всякий случай)
└── README.md
```

## Быстрый старт (XAMPP)

### 1. Установи и запусти XAMPP
- Включи **Apache** и **MySQL**

### 2. Скопируй веб-часть
Скопируй папку `web` в:
```
C:\xampp\htdocs\itch-steam-like\
```

(или просто переименуй `web` → `itch-steam-like` и положи в htdocs)

### 3. Открой в браузере
```
http://localhost/itch-steam-like/
```

При первом заходе:
- Создастся база `itch_steam_local`
- Создадутся все таблицы
- Добавятся демо-игры

### 4. phpMyAdmin
```
http://localhost/phpmyadmin/
```
База: `itch_steam_local`

## Что уже есть

- **Каталог — только готовые игры** (карточки в стиле itch.io, поиск, жанры, сортировка)
- Кнопки прямо на карточках: «В библиотеку» (бесплатно), «Купить» (платно), «В библиотеке» (уже есть)
- **Мастерская** — ассет-паки, звуки, UI-киты и инструменты (те же карточки с покупкой)
- **Страница игры как на itch.io**: галерея скриншотов, описание, теги, сборки, комментарии, оценка звёздами
- **Библиотека как в Steam — только в десктоп-клиенте**: список слева, детали справа, запуск оттуда
- **Загрузки как в Steam**: очередь, живой прогресс, скорость, пауза с докачкой (HTTP Range), история
- **Профиль как в Steam**: уровень, статистика, недавняя активность, настройки аватара, пополнение баланса
- Покупки за внутренний баланс (учебные рубли), история покупок
- Реальная регистрация / логин (сессии в БД, CSRF, кука catio_sid)
- Автосоздание таблиц + демо-данные (игры, ассеты, комментарии, сборки)
- Процедурные обложки и скриншоты (media.php, чистый SVG без GD)
- Демо-файлы сборок генерируются при первом скачивании в `web/files/`
- Чистый код без фреймворков
