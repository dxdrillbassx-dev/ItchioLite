КАРТИНКИ ДЛЯ ИГР — клади файлы в ЭТУ папку (web/covers/)
===========================================================

Имя файла = тип_номер игры.расширение

  cover_1.jpg   — обложка игры с id=1 (карточки в каталоге и на главной)
  hero_1.jpg    — широкий баннер игры с id=1 (большой баннер на Главной)
  icon_1.jpg    — квадратная иконка игры с id=1 (список в сайдбаре слева)

Поддерживаемые расширения: jpg, jpeg, png, webp.

Номер игры (id) смотри:
  • в адресной строке страницы игры: .../index.php?view=game&id=1
  • или в phpMyAdmin: база itch_steam_local → таблица games → колонка id

Рекомендуемые размеры:
  cover — 640×360 и больше (16:9)
  hero  — 1600×900 и больше (16:9, важное — по центру)
  icon  — 256×256 (квадрат)

Если файла нет — CATio сам рисует заглушку, как раньше.
hero и icon не обязательны: если их нет, используется cover.
